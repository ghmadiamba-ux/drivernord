# 02 — Real Market Examples: Companies Using These Models

**Research date:** 2026-05-12  
**Scope:** Real companies operating qualification-based recruitment monetization in Sweden, Nordic, Europe, UK, and US. Priority: verified companies with documented pricing.

---

## KEY FINDING — HIGHEST CONFIDENCE

> **The strongest direct evidence that DriverNord's model is commercially viable is that two Swedish companies — Chaffis.se and Förartjänst.se — already charge Swedish åkerier for driver database access and matching. The market has already validated willingness to pay. DriverNord's differentiation is verification quality and intelligence.**

---

## Sweden — Direct Competitors / Analogs

### Company 1: Chaffis.se

| Field | Detail |
|-------|--------|
| **Country** | Sweden |
| **Website** | chaffis.se |
| **Founded** | ~2020 (launched July 2020 per Tidningen PROFFS) |
| **Sector** | Professional truck driver + åkeri matching |
| **Model type** | Annual subscription for companies + per-contract signing fee |
| **Pricing visible** | Yes — publicly stated |
| **Price amount** | 4,995 SEK/year (unlimited access) + signing fee per contract |
| **Price currency** | SEK |
| **Pricing unit** | Annual subscription + per-assignment |
| **Payment trigger** | Annual recurring + per signed employment contract |
| **Qualification definition** | Driver self-reported license class; employer specifies criteria; automated match filter |
| **Candidate consent required** | Yes — driver must register and confirm willingness to be contacted |
| **Guarantee / replacement** | None stated |
| **Blue-collar relevance** | Very high |
| **Driver relevance** | 10/10 — CE/C/D specific |
| **SME fit** | Very high — 4,995 SEK/year is affordable for any åkeri |
| **Notes** | Drivers can keep profile private until they choose to share with a specific company. BankID signing for contracts. No employment by platform. Automated matching on license class and availability. Social media distribution of job posts. |
| **What DriverNord can copy** | Subscription pricing model; BankID contract signing; social media job distribution; privacy-first consent model |
| **What DriverNord should avoid** | No quality verification — DriverNord must add license validity checking and YKB confirmation |
| **Source URL** | [chaffis.se/för-åkerier](https://www.chaffis.se/f%C3%B6r-%C3%A5kerier) |
| **Source reliability** | 5 (direct pricing page) |

### Company 3: Headscout.se

| Field | Detail |
|-------|--------|
| **Country** | Sweden |
| **Website** | headscout.se |
| **Sector** | General recruitment — flat-fee model |
| **Model type** | Flat-fee recruitment (split: upfront + on-hire) |
| **Pricing visible** | Yes |
| **Price amount** | 15,000 SEK upfront + 59,900 SEK on candidate signing = **74,900 SEK total** |
| **Price currency** | SEK |
| **Pricing unit** | Per placement |
| **Payment trigger** | 1st: engagement, 2nd: candidate signs contract |
| **Qualification definition** | Candidate hired by client |
| **Candidate consent** | Not stated (standard agency consent implied) |
| **Guarantee** | Not explicitly stated in reviewed content |
| **Driver relevance** | Low (not driver-specialist) |
| **SME fit** | Medium (74,900 SEK is expensive for micro åkeri) |
| **Notes** | "Price ceiling" positioning — salary of hired candidate doesn't affect total cost. This is a stronger value proposition for transport where candidates have similar salaries. Background checks and credit checks included. 30+ years, 5,000+ placements. |
| **What DriverNord can copy** | Split payment structure (upfront + success); flat fee positioning as "price ceiling"; background check included |
| **What DriverNord should avoid** | Price point too high for SME åkeri; should start lower |
| **Source URL** | [headscout.se/fast-pris](https://www.headscout.se/kopia-av-rekrytering2/) |
| **Source reliability** | 5 (direct pricing page) |

### Company 4: SV Bemanning / bemanningrekrytering.se

| Field | Detail |
|-------|--------|
| **Country** | Sweden |
| **Website** | bemanningrekrytering.se |
| **Sector** | Transport staffing + recruitment |

| **Price amount (recruitment)** | 15–25% of annual salary |

| **Payment trigger** | Monthly invoice (staffing) / candidate hire (recruitment) |
| **Qualification definition** | Valid C/CE/D license + YKB + ADR where required |
| **Candidate consent** | Not stated |
| **Guarantee** | Replacement guarantee within warranty period |
| **Driver relevance** | 10/10 |
| **Notes** | Transparent pricing range published on FAQ. 24-hour start for staffing. "Nöjd-kund-garanti." No binding period for staffing contracts. This is real, documented Swedish transport staffing/recruitment pricing. |
| **What DriverNord can copy** | Transparent pricing ranges published on website; CE/YKB standard as qualification definition; replacement guarantee |
| **Source URL** | [bemanningrekrytering.se/faq](https://bemanningrekrytering.se/faq-bemanning-rekrytering/) |

### Company 9: Instawork (USA/Canada)

| **Website** | instawork.com |

## Service Marketplaces with Pay-Per-Lead Models (Benchmark)

### Company 12: Bark.com (UK/Global)

| Field | Detail |
|-------|--------|
| **Country** | UK (global) |
| **Website** | bark.com |
| **Sector** | Service professional marketplace (tradespeople, consultants, cleaners) |
| **Model type** | Pay-per-lead (credit purchase) for service professionals |
| **Pricing visible** | Yes |
| **Price amount** | ~$3–8 per lead (credit-based; higher for larger/specialized jobs) |
| **Payment trigger** | Professional pays per lead purchased |
| **Notes** | No monthly fee. Credits purchased in bundles. Professionals only see leads they're qualified for. Up to 5 professionals can pay for the same lead (competition). No commission on completed work. |
| **Driver relevance** | Low (not driver-specific) |
| **SME fit** | N/A — this is the service-provider (driver equivalent) paying, not the employer |
| **What DriverNord can copy** | Credit model for driver-side could work: drivers pay small credit to express interest in a role. BUT — Swedish market convention is that employers pay, not workers. Use with caution. |
| **Source URL** | [bark.com/en/us/sellers/pricing](https://www.bark.com/en/us/sellers/pricing/) |
| **Source reliability** | 5 (direct pricing page) |

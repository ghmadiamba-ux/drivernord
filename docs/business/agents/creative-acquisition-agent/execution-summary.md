## What Claude Code Builds Next

These are implementation tasks, in priority order. All specification documents exist. This is the build phase.

### Priority 1 — Creative bank file structure (Day 1, ~30 min)

Create all folders and stub files under `docs/business/agents/creative-acquisition-agent/creative-bank/`. Copy angle entries from `content-angle-library.md` into individual angle files. Create performance log and content calendar templates.

This can be done immediately, before any other code.

### Priority 2 — `lib/agents/creativeAgent.ts` (Days 1–2, ~4–6 hours)

The main agent function. Reads creative bank, assembles system prompt, calls Claude Sonnet, runs compliance check, writes output to file, returns structured output. This is the core of the MVP.

### Priority 3 — `lib/agents/creativeComplianceCheck.ts` (Day 2, ~2 hours)

The compliance check runs after every generation. Catches forbidden phrases before they reach the founder's review queue. Uses Claude Haiku (fast and cheap for this classification task).

### Priority 4 — `app/api/agent/creative/route.ts` (Day 2–3, ~2 hours)

The API endpoint. Protected by `requireRecruiterAuth()`. Takes `CreativeAgentInput`, returns `CreativeAgentOutput`. Founder calls this from the cockpit or Claude Code CLI.

### Priority 5 — `lib/agents/weeklyContentPlan.ts` (Day 3, ~3 hours)

The weekly plan generator. Called first every Monday. Reads performance log and angle library, generates a 3–4 post plan with rationale. Output is a Markdown document saved to `creative-bank/content-calendar.md`.

### Priority 6 — Tests (Day 4, ~3 hours)

Unit tests for all functions. Integration test for the full pipeline. See `mvp-implementation-plan.md` for test specifications.

### Priority 7 — `lib/agents/creativePerformanceAnalysis.ts` (Day 5, after first data exists)

The performance analysis function. Only useful after at least 2 weeks of published content and entered data. Build this after the production cycle has run.

**Total estimated build time: 3–5 days of Claude Code work.**

## First 14 Days of Organic Content

This is the recommended content schedule for weeks 1–2. All content is generated by the Creative Agent, reviewed by the founder, and published manually in Meta Business Suite.

**Prerequisite before day 1:** Facebook Page exists.

### Day 1 (Tuesday) — Launch Post

**Platform:** Facebook Page
**Angle:** 07 — Förtroendet (Trust building)
**Format:** Medium-form text post
**Purpose:** Establish what DriverNord is before asking anyone to register. This is not a registration-drive post — it is a credibility post.

**Draft brief for agent:**
- Persona: All (general awareness)
- Format: 150–200 words
- Hook: Transparent/behind-the-scenes ("Här är vad DriverNord faktiskt gör")
- Must include: What DriverNord is, what it is not, consent model, registration link
- Tone: Honest, grounded, no hype

### Day 3 (Thursday) — First Acquisition Post

**Platform:** Facebook Page
**Angle:** 01 — Frustrationen
**Format:** Short-form text post (80–100 words)
**Purpose:** First real registration-drive post. Test the frustration angle with a clean, short hook.

**Draft brief:**
- Persona: CE experienced
- Hook: Question format ("Trött på att skicka in ansökan och aldrig höra nåt?")
- CTA: Link to `drivernord.se/chat` with UTM `angle01_frustration_v1`

### Day 5 (Saturday) — Group Post (if group joined)

**Platform:** Facebook Group (one group, most relevant)
**Angle:** 08 — Invändningshantering (FAQ format)
**Format:** Conversational FAQ post, no branded visuals
**Purpose:** Organic reach in groups; informational framing, not promotional

**Note:** Adapt the brand voice for group context. Less "we are DriverNord" and more "this is how this service works." End with a soft mention, not a hard CTA.

---

### Week 2 — Testing Phase

**Goal:** Test two more angles. Gather first data. Refine one post based on early engagement signals.

### Day 8 (Tuesday) — Consent Angle

**Platform:** Facebook Page
**Angle:** 03 — Kontrollen (Consent & Control)
**Format:** Medium-form text, possibly with simple graphic (Canva)
**UTM:** `angle03_consent_control_v1`

**Why this week:** The consent angle is the strongest differentiation from staffing agencies. It needs to be tested early. If it performs well, it becomes a cornerstone of all future content.

### Day 10 (Thursday) — Instagram First Post

**Platform:** Instagram
**Angle:** 02 — CE-identiteten
**Format:** Short caption + static image (Canva brief provided by agent)
**UTM:** `angle02_ce_identity_v1` (via link in bio)

**Why:** Instagram requires different formatting and a visual. This tests the channel. If Instagram shows engagement, include it in the regular rotation.

### Day 12 (Saturday) — Frustration Angle Variant

**Platform:** Facebook Page
**Angle:** 01 — Frustrationen (new variant)
**Format:** Short-form text post
**UTM:** `angle01_frustration_v2`

**Why:** If day 3 post showed any engagement, a second variant tests whether the angle repeats or the first post was an outlier.

---

### Day 14 — First Performance Review

The founder reviews 2 weeks of data and enters into `performance-log.md`:
- Which posts got the most link clicks
- Which UTM tags appear in Supabase (chat starts, registrations)
- Any comments on posts (qualitative feedback)

The Creative Agent then generates its first performance analysis. The founder reads it and decides:
- Which angles to continue
- Which to pause
- What to test in weeks 3–4

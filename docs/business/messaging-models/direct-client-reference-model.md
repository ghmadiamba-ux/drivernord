## 1. Purpose

This model is the reference base for direct-client outreach at DriverNord.

It is designed for transport and logistics companies that have a concrete, observable operational need for workers — drivers, warehouse staff, terminal personnel, or logistics capacity in general. It is not a generic recruitment advertisement and does not read as one.

The model opens a professional conversation from a position of domain understanding. It signals that DriverNord knows the specific segment, understands what the need actually involves, and can present relevant profiles — not a generic pool of applicants.

DriverNord's three commercial paths are all accessible from this model:
- **Matchning / Kortlist** — fee per accepted candidate profile
- **Rekrytering / Introduktion** — permanent hire facilitation
- **Bemanning / Logistikpersonal** — employed workers available for assignment (when prerequisites are in place)

The email does not need to specify which path applies at first contact. The goal is to open a conversation, not to close a sale.

---

## 2. When to Use

Use this model for:

- Transport companies (åkerier) of any size
- Distribution operators (lokal och regional distribution)
- Kyl/frys operators (kylfrys, temperaturkontrollerad logistik)
- Schakt/bygg transport companies (mark, anläggning, tipp)
- Terminal operators (gods, spedition, sortering)
- Warehouse/lager operators (3PL, e-handel, B2B lager)
- Companies with a visible, inferred, or recurring workforce need
- Companies with a recent job posting in the relevant segment
- Companies where scan data confirms active recruitment activity

Use this model for **first contact** when no previous email or call has been made, and when no other DriverNord model already governs this target.

---

## 3. When NOT to Use

Do **not** use this model for:

- Bemanningsföretag or rekryteringsbyråer — these require the agency outreach model (not yet created; see `agency-partnership-model.md` for context)
- Companies with `do_not_contact`, `bankrupt`, or `rejected` status in the system
- Companies already in an active conversation with another open model
- Enterprise targets where a structured account-based approach is needed (large fleet operators requiring multi-stakeholder contact)
- Follow-up contacts where a previous model already governs the sequence (e.g., Enskede Bilexpress and Edvardssons — see cross-references below)
- Targets with no concrete need identified (do not speculate into an outreach)

## 6. CTA Variants

Three approved CTA variants. Use the default unless a specific context justifies an alternative.

**A — Soft call scheduling (default)**
> *"Om detta är aktuellt hos er, svara gärna med en tid som passar för ett kort samtal — annars ringer jag gärna upp vid ett tillfälle som passar er bättre."*

**B — Founder will call if easier**
> *"Om det passar bättre ringer jag gärna upp vid ett tillfälle som fungerar för er."*

**C — Short reply**
> *"Det räcker gärna med ett kort svar om behovet fortfarande är aktuellt."*

**Preferred default CTA:**
Variant A — it offers both reply and call, puts the scheduling initiative with the prospect, and avoids the presumption of a cold call arriving unannounced.

Use Variant C when the target has been previously contacted and a minimal nudge is more appropriate than a full scheduling offer.

Use Variant B in follow-up sequences where a call has already been mentioned and the prospect has shown no resistance.

## 7. Guardrails

These apply to every email using this model. No exceptions.

| Rule | Detail |
|------|--------|
| No AI mention | Never reference AI, algorithms, or automated systems in the email body |
| No "gratis" | Never use "gratis", "kostnadsfri", or "0 kr" in any form |
| No candidate oversupply claim | Never imply you have a pool ready to deliver immediately; say "vi presenterar" not "vi har" |
| No staffing company claim | DriverNord is not an authorized staffing company (bemanningsföretag); do not imply licensed staffing status |
| No private data in email | Never include driver names, personal data, or contact details in the outreach email |
| No Jobwise mention | When approaching KoF or any client with a known existing supplier, never name that supplier — see `kof-message-and-positioning.md` |
| No old phone number | Use 070-938 52 67 only; 0730681181 is retired and must not appear |
| No closed-off bemanning language | Do not write "vi erbjuder inte bemanning" or frame bemanning as categorically out of scope; the phrase *"ett mer praktiskt kapacitetsupplägg"* in the template covers this correctly |
| Agency targets require separate model | Bemanningsföretag and rekryteringsbyråer are not direct clients; use the agency partnership model instead |
| Founder approval before sending | No email using this model may be sent without explicit founder review and approval |
| Signature must match | Always: Ghislain Alexander Mad / DriverNord / Matchning av yrkesförare och logistikpersonal / drivernord.com / hej@drivernord.com / 070-938 52 67 |
